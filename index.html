Oracle Backend with Firebase APIs Fusabase demos

Three small demos that together form a todo application backed by an Oracle Database through Oracle Backend with Firebase APIs. Sign in once in the first demo — the session carries over to the other two.

  • Demo 1

    Authentication

    Email/password sign-up and sign-in, plus Google federated login.
  • Demo 2

    Database

    A per-user todo list on Firestore-style collections, guarded by security rules.
  • Demo 3

    Storage

    File attachments per user with resumable uploads and download URLs.
  • Demo 4

    Realtime

    The same todo list on two devices, kept in sync with onSnapshot.
